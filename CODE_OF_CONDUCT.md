# Code of conduct

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1. The full text is available at that link and applies where this summary is silent.

## Our commitment

We want participating in this project to be a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be direct about code and generous about people.
- Assume the other person read the code and reached a different conclusion, not that they were careless.
- Accept that a security judgement call may go against you; argue the threat model, not the person.
- Give and take technical criticism gracefully. "This rule produces a false positive on X" is useful; "this is obviously wrong" is not.

## Unacceptable behaviour

- Harassment, intimidation, or discrimination in any form.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Personal or political attacks, trolling, and deliberate derailing.
- Publishing someone's private information without explicit permission.
- Publishing a real credential or a private vulnerability detail in a public thread. This one is specific to this project: it is a security incident, not just rudeness.

## Scope

This applies in issues, pull requests, discussions, commit messages, code comments, and anywhere someone is representing the project.

## Enforcement

Report a problem privately to the maintainer, [@Amor-130625](https://github.com/Amor-130625). If confidentiality matters, use a [private security advisory](https://github.com/Amor-130625/mcpvet/security/advisories/new) with the subject "code of conduct". Reports are handled confidentially. The maintainer will respond within seven days with the action taken, which may range from a private conversation to a permanent ban, depending on severity and pattern.

Maintainers who do not follow or enforce this code in good faith may face temporary or permanent consequences as determined by the other maintainers.
